# Psychonauts 
## In the Rhombus of Ruin
###### Funcionalidades:
Em contraste com Psychonauts original, Psychonauts In the Rhombus of Ruin não é um plataformer 3D, mas sim um jogo de realidade virtual (primeira-pessoa), com foco em puzzles, como uma aventura point-and-click.

###### O que aprendi:
* Como clonar um repositório com `git clone`
* Como registar alterações com `git add`, `git commit` e `git push`
* Como sincronizar cópias diferentes com `git pull`
